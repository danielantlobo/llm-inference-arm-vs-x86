The main challenges when running large transformer models on CPU-only systems are the high memory footprint of these models and the repeated loading of weights during the decoding phase. The high memory footprint is due to the large number of parameters in the model, while the repeated loading of weights is due to the need to access the model's weights multiple times during the decoding process. Quantisation can help address these challenges by reducing the number of bits required to represent the model's weights, thereby reducing the memory footprint, and by allowing for the use of lower-precision arithmetic during the decoding process, thereby reducing the time required to load the weights. This can significantly improve the performance of large transformer models on CPU-only systems.
