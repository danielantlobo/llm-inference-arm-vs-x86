1. Memory Footprint: The main challenge is the large memory footprint of transformer models. Transformers store embeddings for each token, which can be in the tens of billions for billions of values, leading to a massive memory requirement for storing and loading these embeddings during training and inference. This memory footprint becomes a bottleneck, especially for the memory is limited on CPU-only systems.

2. Weight Loading During Decoding: During inference, transformers need to load their weights repeatedly to compute the attention mechanism. This leads to inefficient use of CPU resources and longer inference times.

3. Quantization: Quantization is a technique that reduces the precision of weights and activations in a model to save on memory and computational cost. When quantizing a transformer, it can be done in two ways: binary quantization, where weights are quantized to binary values, and integer quantization, where weights are quantized to integers. These quantized models are smaller, consume less memory, and are faster to compute. By using quantization, it can help address the memory footprint and weight loading challenges of running large transformer models on CPU-only systems. Additionally, quantized models can be further optimized for specific hardware and use cases, ensuring efficient inference and better performance.
