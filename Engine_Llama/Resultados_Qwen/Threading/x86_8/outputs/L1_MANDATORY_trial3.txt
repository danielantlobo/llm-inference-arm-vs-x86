Quantisation refers to the process of reducing the number of bits used to represent the weights and activations in a neural network, which can significantly reduce the memory requirements and speed up inference. However, quantisation also requires careful tuning to avoid degradation in model performance. Specifically, quantisation can cause the model to become less capable of capturing long-range dependencies in the input data, which is a crucial aspect of transformer architectures. Therefore, quantisation is a powerful tool for improving the efficiency of large transformer models, but it requires careful tuning to balance the trade-off between memory usage and inference speed. This is an ongoing area of research in the field of transformer models.
