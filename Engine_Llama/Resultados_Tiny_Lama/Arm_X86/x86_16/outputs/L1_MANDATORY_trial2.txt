When running large transformer models on CPU-only systems, the main challenges arise from the high memory footprint of the model, which means that the model cannot be loaded and executed in a single process. As a result, the model must be loaded and executed in chunks, which can lead to latency issues and bottlenecks in the system. Additionally, the model's large memory footprint means that the CPU cannot efficiently perform computations on the model's weights. 

To address these challenges, quantisation is a popular technique in the transformer community. Quantising the model's weights helps to reduce the memory footprint of the model without compromising its performance. Quantising reduces the model's memory footprint by eliminating the need for floating point calculations that are not needed, while still retaining the original model's accuracy. This ensures that the model remains computationally efficient when running on CPU-only systems, even with a large memory footprint.
