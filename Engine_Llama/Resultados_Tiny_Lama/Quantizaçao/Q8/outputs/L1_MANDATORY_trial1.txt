1. Memory footprint: The memory footprint of a large transformer model is huge. Each layer requires the input and output tensors of the previous layer to be stored in the memory, which can consume a significant amount of memory. A common approach is to divide the model into smaller sub-models, each with its own weights and biases, and train them independently. This reduces the memory footprint of each sub-model, but it can result in slower training times due to the need for multiple GPUs to work on each sub-model. Quantisation helps address this challenge by reducing the input and output tensors of the model to a smaller range of values. This reduces the memory footprint of the model while maintaining its performance.
2. Parallelism: Transformers can be processed in parallel across multiple GPUs, but each GPU has its own memory, making it challenging to efficiently distribute the model across multiple GPUs. Quantisation helps address this challenge by converting the model’s weights and biases into a smaller range of values that can be stored in the memory of multiple GPUs. This allows for more efficient parallelism across multiple GPUs, resulting in faster inference times.
