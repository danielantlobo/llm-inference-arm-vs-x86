1. Memory footprint: Transformers require a large amount of memory to store their weights and intermediate states. When training on a single CPU, this memory footprint can be quite large, which can be a limiting factor in terms of performance. 2. Repeated loading of weights: The same weights are loaded on every step during the decoding phase, which can significantly increase the memory footprint and the computational overhead. Quantising the weights can help address this issue by reducing the number of weights that need to be loaded, which can lead to better performance. This is because quantisation reduces the precision of the weights, which results in fewer errors and a better fit to the input data. 3. Low-power CPUs: The main drawback of CPUs is their low power consumption. Transformers require a lot of power to run, which can be a problem if the CPU is running in a low-power mode. Quantising the weights can help address this issue by reducing the power consumption without compromising performance. By combining these benefits, quantised transformers can offer a competitive performance to their CPU counterparts while being more energy-efficient.
