1. Memory Footprint: Transformers are typically larger than traditional recurrent neural networks, which can cause significant memory usage issues. When training on CPU, the large memory footprint can cause the system to run out of memory and fail. Quantisation can help address this by reducing the model’s memory footprint without compromising its performance. By scaling down the model’s weights and activations, the memory footprint is reduced, and the model’s performance can be maintained.
2. Loading Weights During Inference: When deploying transformers for inference on CPU, the model requires the loading of weights during each inference. This can cause a significant slowdown and memory usage due to the repeated loading of the weights. Quantisation can help address this by reducing the model’s memory footprint and improving its performance. The quantisation process reduces the model’s parameters, which can make the model’s performance more consistent and less sensitive to changes in the input data.
