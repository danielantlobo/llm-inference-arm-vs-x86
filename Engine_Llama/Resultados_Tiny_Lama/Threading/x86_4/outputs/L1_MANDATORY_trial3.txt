1. Memory footprint: When running large transformer models on CPU, the main challenge is the memory footprint. The transformer requires a large number of parameters to be fully trained and the memory usage during training can be significant. Quantisation helps by reducing the size of the weights used during training, thus reducing the memory footprint.
2. Decoding phase: When deploying large transformer models for inference on CPU-only systems, the main challenge is the repeated loading of weights during the decoding phase. Quantisation helps by reducing the number of parameters used during training and reducing the weight loading during inference.
3. Precision: Transformer models trained on CPU are not designed for inference, so the precision of the parameters used during training is often not suitable for inference. Quantisation helps by reducing the impact of the precision of the parameters used during training, resulting in more accurate results during inference.
4. Implementation: Deploying transformer models for inference on CPU-only systems often requires a different implementation than when training on GPU. Quantisation helps by reducing the number of parameters used during inference, resulting in more accurate results.
