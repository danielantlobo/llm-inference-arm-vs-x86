When running large transformer models on CPU-only systems, the main challenge is the large memory footprint and repeated loading of weights during the decoding phase. The memory footprint is caused by the need to store tens of thousands of parameters, which makes the model unfit for deployment on CPUs. This is because CPUs do not have the necessary cache memory to store such a large number of parameters. To address this challenge, quantisation is used to reduce the parameter sizes and thus improve the memory footprint.

Quantisation is the process of reducing the parameter sizes of the model, while still maintaining its accuracy. The idea is to use a smaller number of bits than the maximum number of bits used to represent that parameter. The process involves dividing each parameter by a fixed power of 2, resulting in a binary number. For instance, the parameter of a 1024-dimensional input feature vector can be quantised to a binary number with 26 bits, resulting in a parameter size of 1024 bits.
